어떤 서비스인가요?

유니티로 게임을 만들다 보면 개념, 설계, 디버깅에서 자주 막힙니다. 유니티 훈련소는 그런 부분을 문제로 풀어 보며 익히도록 만든 학습 도구입니다. 개발 동아리 스터디용으로 만들었고, 누구나 둘러볼 수 있습니다.

이렇게 풀어요

  1. 상황과 목표를 읽습니다. 문제마다 상황 설명, 통과 조건, 제한이 있습니다.
  2. 코드를 직접 작성합니다. 줄 번호가 있는 편집기에 C# 코드를 씁니다.
  3. 조건별로 채점받습니다. 어느 조건이 왜 틀렸는지 표시되고, 오류에는 줄 번호가 붙습니다.
  4. 막히면 힌트를 한 단계씩 엽니다. 정답은 한 번 채점한 뒤에만 볼 수 있습니다.
  5. 푼 문제는 복습으로 돌아옵니다. 1·3·7·16·35일 간격으로 다시 풀고, 비슷한 문제는 문제 사전에서 더 풉니다.

채점은 브라우저 안에서 C# 코드를 직접 읽어 실행하는 방식이라, 설치 없이 바로 쓸 수 있습니다. 실제 Unity 에디터와 완전히 같지는 않으니 학습용으로 사용해 주세요.
