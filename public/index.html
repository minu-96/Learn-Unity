유니티 훈련소

Unity와 C#을 문제로 배우는 코드 작성 연습장. 읽고 고르는 퀴즈가 아니라, 직접 코드를 써서 조건별로 채점받아요.

이렇게 풀어요

  1. 상황과 통과 조건을 읽어요.
  2. C# 코드를 직접 작성해요.
  3. 어느 조건이 왜 틀렸는지 조건별로 채점받아요.
  4. 막히면 힌트를 한 단계씩 열고, 푼 문제는 복습으로 돌아와요.

학습 단계

입문(코딩 첫걸음) → 기초(C# 문법·Unity 구조) → 응용(컴포넌트·물리·애니메이션) → 심화(연출·설계·최적화)
