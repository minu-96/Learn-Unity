서비스 소개

유니티 훈련소는 Unity와 C#을 문제로 배우는 코드 작성 연습장이에요. 유니티로 게임을 만들다 막히는 개념, 설계, 디버깅을 직접 코드를 써서 풀어 보며 익혀요. 개발 동아리 스터디용으로 만들었고, 누구나 둘러볼 수 있어요.

한 문제는 이렇게 풀어요

  1. 상황과 목표를 읽어요. 문제마다 상황 설명, 통과 조건, 제한이 있어요.
  2. 코드를 직접 작성해요. 줄 번호가 있는 편집기에 C# 코드를 써요.
  3. 조건별로 채점받아요. 어느 조건이 왜 틀렸는지 표시되고, 오류에는 줄 번호가 붙어요.
  4. 막히면 힌트를 한 단계씩 열어요. 정답은 한 번 채점한 뒤에만 볼 수 있어요.
  5. 푼 문제는 복습으로 돌아와요. 1·3·7·16·35일 간격으로 다시 풀고, 비슷한 문제는 문제 사전에서 더 풀 수 있어요.

채점은 브라우저 안에서 C# 코드를 직접 읽어 실행하는 방식이라 설치가 필요 없어요. 실제 Unity 에디터와 완전히 같지는 않으니 학습용으로 써 주세요.
