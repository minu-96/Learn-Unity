# 유니티 훈련소 버전 기록

각 버전은 GitHub 브랜치 `version/v0.1` … `version/v1.0`에 보관돼요(이 환경에서는 태그를 올릴 수 없어 브랜치로 저장). 보려면 `git checkout version/v0.3`, 돌아오려면 `git checkout main`. 로컬에는 같은 이름의 태그도 만들어 두었어요.

## 0. 아티팩트 시기 (10/24 ~ 10/29, GitHub 이전)
첫 메시지(10/24)로 만든 아티팩트를 같은 주소에서 계속 고쳐 왔기 때문에 시기별 화면은 따로 남아 있지 않아요. 이 채팅의 요청 기록과 그때 남긴 작업 보고를 읽어 단계별로 정리했어요. 코드 파일 자체는 복원하지 못했고, 게시 시각(KST)과 단계의 짝은 시각 기준이에요.

### a. 10/24 15:37 — 첫 아티팩트
- **요청(15:25)**: 유니티로 게임을 만들 때 모르는 개념·설계·디버깅에서 막히는 일이 많아서, 게임 개발 실력을 올릴 학습 도구를 만들고 싶다.
- **구성**: 5개 카테고리(C# 문법, Unity 핵심, 설계, 디버깅, 수학·벡터) × 3단계(입문·응용·실전), 문제 23개.
- **문제 유형**: 객관식, 버그 줄 클릭, 코드 작성+실행 3가지. 코드 작성 4문제(Time.deltaTime, 왕복 이동, MoveTowards, 상태 전환)는 간이 변환기로 캔버스에서 실행하고 30/60/144fps를 바꿔 볼 수 있었어요.
- **AI 기능**: 문제별 힌트·코드 리뷰·질문하는 AI 튜터, 카테고리/단계를 골라 객관식을 만드는 AI 문제 생성, 문제를 풀면 쌓이고 직접 입력하면 AI가 정리하는 개념 사전.
- **한계**: 벡터 연산자와 키 입력은 지원하지 않았어요. 화면 렌더링과 저장은 그때 직접 확인하지 못했어요.

### b. 10/24 16:01 — 단계·레벨 구조, 카테고리 12개
- **요청(15:52)**: 여러 단계와 레벨로 나눠 달라. 단계는 이론적 흐름, 레벨은 그 안의 난이도. 파티클·게임 주스·연출·컴포넌트 등 게임 개발에 중요한 카테고리도 추가.
- **결과**: 카테고리 5개 → 12개(컴포넌트, 물리·충돌, 애니메이션, 파티클·VFX, 게임 주스, 연출, 최적화 추가), 문제 23개 → 90개.
- 단계마다 이름과 이론 요약(펼쳐 보기), 안에 Lv.1 기본·Lv.2 응용·Lv.3 도전. 87칸 중 86칸을 채웠고 모든 칸에 "AI 문제 추가" 버튼. 객관식 보기 순서는 문제별로 고정해서 섞어 정답이 한 자리에 몰리지 않게 했어요.
- 게임 주스 2단계 Lv.3에 코드 작성 문제(프레임레이트와 무관한 카메라 추적)가 추가됐어요.

### c. 10/24 16:52 — 코드 작성형 + 자동 채점
- **요청(16:04)**: 4지선다는 절대 안 가져간다. 문제·제한·조건 설명을 보고 직접 코드를 쓰고, 스크립트를 채점해서 무엇이 틀렸는지·잘했는지 알려 달라. 객관식은 학습이 아니라 지식 시험이다.
- **결과**: 4지선다를 모두 없애고 90문제 전부 코드 작성형으로 전환. 상황·목표·제한·쓸 API가 있고 줄 번호 편집기에 직접 작성해요.
- 채점은 두 단계: 코드 패턴 검사(컴파일 오류까지) → 코드를 실제로 실행해 동작 검사. 조건마다 ✓/✗와 이유 표시, 단계별 힌트, 정답은 한 번 채점한 뒤에만 열림, 통과하면 해설과 개념 사전 반영. 작성 중인 코드 자동 저장.
- AI는 코드 리뷰·질문·AI 판정(자동 채점이 틀린 것 같을 때)·AI 문제 추가. 예전 객관식 진행 기록은 이어받지 않고 개념 사전만 가져왔어요.

### d. 10/24 20:16 — 채점 엔진 교체·복습·Lv.3 강화
- **요청(17:27, 19:40)**: 현재 아티팩트의 학습 효과를 평가하고 장단점·보완책·작업 모델을 제안해 달라 → 바빠서 직접 플레이 테스트하며 전부 수정해 달라.
- **채점 엔진**: 학생 코드를 JavaScript로 바꿔 돌리던 방식을 버리고 C# 코드를 직접 읽어 실행하는 인터프리터로 교체. 실행을 막는 보안 설정에서도 90문제가 모두 통과했어요. 벡터 연산자, 프로퍼티, 여러 클래스·상속, switch 식, out/ref, Dictionary·Queue 지원, 정수 나눗셈·배열 범위 오류·foreach 중 수정 에러·`float x = 0.5;` 컴파일 에러까지 Unity처럼 재현. 이름·모양을 강요하던 채점 규칙 약 30개를 동작 검사로 바꾸거나 완화. 에러에 줄 번호와 "N번째 줄로 이동", 도구가 모르는 문법이면 AI 판정 안내.
- **학습 구조**: 복습 탭 신설(1·3·7·16·35일 간격, 정답 보기·AI 판정 통과 문제는 더 빨리, AI 변형 문제), 통과 방식 구분 표시(자력/정답 참고/AI 판정), Lv.3 11문제는 원인을 빼고 증상만 남기고 원인은 첫 힌트로, 30개 단계마다 "Unity에서 직접 해보기" 체크리스트.
- **검증**: 90문제 시작 코드 실패·정답 통과, 학생 풀이 59개·코드 모양 변형 테스트 통과, 모바일 가로 스크롤 없음. 실제 AI 응답은 가짜 응답으로만 확인.
