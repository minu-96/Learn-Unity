# 운영 가이드

## 운영진 화면 (`/#admin`)
- **요약**: 가입 부원, 최근 7일 활동, 14일 이상 미활동, 구간별 수료 인원
- **부원 현황**: 이름 / 마지막 접속 / 입문·기초·심화 진행 / 자력 비율 / 복습 유지율. 검색, 정렬, 14일 미활동 필터, CSV 내려받기
- **많이 막히는 문제**: 2명 이상이 시도한 문제 중 해결률이 낮고 정답을 참고한 사람이 많은 순
- **채점 오류 신고**: 부원이 "채점이 이상해요"로 보낸 코드와 실패 항목. 확인 후 "처리됨"으로 표시

## 지표 정의
| 지표 | 의미 |
|---|---|
| 해결 | 채점을 통과한 문제 수 |
| 자력 | 해결 문제 중 정답 보기를 쓰지 않고 통과한 비율 |
| 수료 | 구간 문제의 80% 이상 해결 **그리고** 푼 문제의 60% 이상 자력 |
| 복습 유지율 | 복습을 한 문제 중 현재 복습 상자가 1단계 이상인 비율(첫 시도에 통과해 기억이 이어지는 문제) |

수료 기준은 `public/js/tiers.js`의 `PASS_SOLVED`, `PASS_SELF`에서 바꿉니다.

## 학습 구간
| 구간 | 분야·단계 | 문제 수 |
|---|---|---|
| 입문 | C# 문법 1·2, Unity 핵심 1·2, 컴포넌트 1, 수학 1, 디버깅 1 | 21 |
| 기초 | C# 문법 3, Unity 핵심 3, 컴포넌트 2, 물리, 애니메이션, 파티클 1·2, 수학 2 | 30 |
| 심화 | 파티클 3, 게임 주스, 연출, 설계, 디버깅 2, 최적화 | 39 |

## 자율 과제형으로 운영할 때
- 부원에게 "이번 달: 입문 수료" 같은 구간 단위 목표를 주고, 운영 화면의 미활동 필터로 챙길 사람을 찾습니다.
- 막히는 문제 목록은 스터디 모임에서 같이 풀 문제를 정하는 근거로 씁니다.
- 채점이 틀렸다는 신고가 오면 코드를 `tests/play.js`에 추가해 같은 오류가 재발하지 않게 합니다.
