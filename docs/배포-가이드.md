# 배포 가이드 (Firebase 한 가지만 사용 · Spark 무료 요금제)

필요한 것: 구글 계정, Node.js. 카드 등록은 필요 없습니다(Spark 요금제는 한도를 넘으면 청구 대신 서비스가 멈춥니다).

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → 프로젝트 추가 (Google Analytics는 꺼도 됨)
2. **빌드 → Authentication → 시작하기**
   - 로그인 방법에서 **Google** 사용 설정 (지원 이메일 지정)
   - **이메일/비밀번호** 사용 설정 (운영진 계정용)
3. **빌드 → Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 지역은 가까운 곳)
4. **프로젝트 설정 → 일반 → 내 앱 → 웹 앱(</>) 추가** 후 나오는 `firebaseConfig`를 `public/js/firebase-config.js`의 `apiKey / authDomain / projectId / appId`에 붙여 넣기
   (이 값은 공개용 식별자라 저장소에 올려도 됩니다. 접근 제어는 `firestore.rules`가 합니다.)

## 2. 배포
```bash
npm i -g firebase-tools
firebase login
cp .firebaserc.example .firebaserc   # 프로젝트 ID를 적기
firebase deploy                      # 호스팅 + Firestore 규칙
```
배포되면 `https://<프로젝트ID>.web.app` 주소가 생깁니다. Authentication → 설정 → **승인된 도메인**에 이 주소가 있는지 확인하세요(기본으로 들어 있음).

## 3. 운영진 계정 만들기
운영진은 "아이디 + 비밀번호"로 `https://<주소>/#admin` 에서 접속합니다.
1. Authentication → 사용자 → **사용자 추가**: 이메일에 `아이디@admin.learn-unity.example`, 비밀번호 입력 (예: 아이디 `staff1` → `staff1@admin.learn-unity.example`)
2. 만들어진 사용자의 **UID**를 복사
3. Firestore → **컬렉션 시작** `admins` → 문서 ID에 그 UID, 필드는 아무거나 (예: `ok` = true)
4. 운영진마다 반복

문서가 없는 계정은 로그인해도 운영 데이터를 읽을 수 없습니다(보안 규칙).

## 4. 확인
- 구글 계정으로 접속해 문제 하나를 풀고, 운영진 계정으로 `/#admin`에 들어가 해당 부원이 보이는지 확인
- 문제가 생기면 브라우저 개발자 도구 콘솔의 오류와 Firestore → 규칙 → 모니터링을 확인

## 알아 둘 점
- 비용: Spark 한도(일일 읽기/쓰기 등)는 Firebase 요금 페이지에서 확인하세요. 이 앱은 변경 시 4초 단위로 묶어 저장해 쓰기 횟수를 줄입니다.
- 개인정보: 이름·이메일·진행 현황은 운영진이, 작성 중인 코드와 풀이 기록은 본인만 읽습니다(채점 오류 신고에 첨부한 코드는 운영진이 읽음). 로그인 화면에 안내 문구가 있습니다.
- 운영진 이메일 도메인(`admin.learn-unity.example`)은 가상의 주소라 메일이 오가지 않습니다. 비밀번호 재설정은 콘솔에서 합니다.
